# JavaScript Promises Practice

## Overview

A practical JavaScript project focused on understanding Promises and handling asynchronous operations.

## Concepts Practised

- Creating and handling Promises
- Promise states: pending, fulfilled and rejected
- `.then()`, `.catch()` and `.finally()`
- Promise chaining
- Error handling with `throw` and `.catch()`
- `Promise.all()`
- `Promise.race()`
- `Promise.allSettled()`
- `Promise.any()`
- Asynchronous operations using `setTimeout()`

## Project Structure

```text
javascript-promises-practice/

```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Open Chrome DevTools and select the Console tab.
5. Observe the output of each Promise example.
